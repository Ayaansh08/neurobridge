# Project Context

## What is NeuroBridge?
A private practice space where people rehearse difficult conversations before they happen — job interviews, asking for a raise, setting boundaries, talking to professors, making phone calls.

## Target Users
Anyone who gets anxious before hard conversations and wants a safe space to practice with realistic AI characters.

## Hackathon
- **Event:** AWS Hackathon (open theme)
- **Deadline:** September 20, 2026
- **Tracks:** "Build It" (local) and "Ship It" (AWS services — grand prize track)
- **Demo:** 3-minute recorded video (no live demo)

## Judging Criteria
1. **Idea & Impact** — real problem, real change for users
2. **Built on AWS** — uses AWS services or open-source projects
3. **Learning** — what did you learn building it?
4. **Execution** — does it work? One working feature > five broken ones
5. **Demo video** — 3 min showing what, who, and where AWS fits

## Team
Collaborative — no fixed ownership areas. Leader deploys to AWS.
